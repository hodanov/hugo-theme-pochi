# Plan: P5 レイアウトとコンポーネント

デザイン磨き込みロードマップ（`2026-10-19_design-refinement-roadmap.md`）の P5。P4 で文字・行長・トークンが揃ったので、Bootstrap 風の flex グリッドを CSS Grid に置き換え、カードと関連記事を組み直す。

## Background

- 対象の監査 ID：L-05（`col-*` のグリッド、sticky の `top: 5.5rem`）、L-09（いいね・シェアのレールが目次のある記事にしか出ない）、L-10（768px 未満で `#contents` が中身の幅まで縮む）。
- ロードマップで決めてあること：`layout/shell.css` に置き換えて `col-*` を除く。scrollspy のセレクタは `data-pochi-toc` に移す。レールを常に出す。カードはコンテナクエリで組み、`aspect-ratio`・タグ・`line-clamp` を入れる。関連記事は auto-fill のグリッド。
- 完了条件：`grid.css`・`col-*`・`order` での並べ替えがゼロ。320〜1440px で横スクロールなし。カードの CLS が 0。
- 2026-11-14 にユーザーと決めたこと：狭い幅のカードも「左にサムネ、右に題」のまま（全幅のサムネにはしない）。一覧のカードにタグを先頭 3 つまでリンクで出す。

## Current structure

棚卸し（2026-11-14、main = 55750fd）：

- `layout/grid.css`：`.container-fluid`（最大 1200px、左右に `--pochi-gutter`）、`.row`（負のマージン）、`.col-sm-4`（576px の例外）、`.col-md-{1,2,3,4,7,8,9,12}`、`#sidebar-left` / `#contents` / `#sidebar` の `order`。
- ページごとの列（768px 以上）：
  - 一覧（ホーム・セクション・タグ・アーカイブ）：DOM は本文(7) → 左(2) → 右(3)。`order` で左 → 本文 → 右に並べる。768px 未満は左を隠す。
  - 記事：目次ありはレール(1) / 本文(8) / 目次(3)。目次なしは本文(8) を `.centered` で中央。
  - 固定ページ・404：本文(8) を中央。検索：本文(9) / サイドバー(3)。
- 中身を包むだけの `.row > .col-md-12` が、記事の本文・一覧のカード・コメント・広告・関連記事・ヒーロー・検索のカードにある。
- `nav.css` にも `order` が 4 か所。DOM はロゴ → 言語 → テーマ → メニューボタン → メニューで、Tab の順が見た目とずれていた。
- テストと JS は `#contents`、`#sidebar-left`、`#sidebar-right`、`.post-row`、`.related-post-item` を使う。これらの id とクラスは残す。

## Design policy

### PR の分け方

1. **5A Grid の骨組み**（`refactor/p5a-grid-shell`）：L-05、L-10。列の幅は変えない。
2. **5B レール**（`feat/p5b-post-rail`）：L-09。
3. **5C カードと関連記事**（`feat/p5c-cards`）：コンテナクエリ、`aspect-ratio`、タグ、`line-clamp`、CLS の計測。

### 骨組み（5A）

- `.l-container`：`.container-fluid` と同じ（最大 1200px、左右に `--pochi-gutter`）。nav・パンくず・フッター・ヒーローもこれにする。
- `.l-shell`：768px 以上で `repeat(12, minmax(0, 1fr))`、`column-gap` は gutter の 2 倍。負のマージンとパディングで作っていた Bootstrap の列と幅が同じになる（1280px で本文の列は 768px のまま）。ページの種類はモディファイア（`--list`・`--post`・`--single`・`--search`）にし、`grid-template-areas` で `left` / `contents` / `right` に置く。DOM は本文が先のままで、`order` は要らない。
- 768px 未満は grid にしない（ブロックの縦積み）。`#contents` は幅いっぱいになり、L-10 が消える。
- sticky の `top` は `--pochi-sticky-top`（nav の高さ + 1.5rem）。scrollspy はサイドバーの目次に付けた `data-pochi-toc` を探す。
- nav の DOM を見た目の順（メニューボタン → ロゴ → メニュー → 言語 → テーマ）にして `order` を消す。メニューボタンはデスクトップで隠れ、モバイルのロゴは absolute で中央なので、どちらの幅でも見た目は変わらない。
- 関連記事は 5C の予定だったが、`.col-sm-4` を消すために 5A で auto-fill のグリッド（最小 12rem）にした。1280px では今の 3 列と同じ幅になる。
- stylelint：`order` と、`.row` / `.col-` / `.container-fluid` / `.centered` のセレクタをエラーにする。

### レール（5B）

- 目次の無い記事にもいいね・シェアのレールを出す。目次なしは本文を今と同じ中央の 8 列（3〜10 列目）に置いたまま、レールを 2 列目に置く。

### カード（5C）

- `media.css` の `padding-bottom` の比率のハックを `aspect-ratio` にする。
- 一覧のカードを `container-type: inline-size` にし、grid（サムネ・題・日付・要約・タグ）で組む。狭いとき（30rem 未満）はサムネ 6rem、広いときは `clamp(8rem, 30%, 14rem)`。要約は 3 行で切り、題は切らない。
- タグは先頭 3 つをチップのリンクにし、カードのリンク（`::after`）より上に置く。検索結果のカードは索引にタグが無いので出さない。
- CLS：ホームの 375 / 1280px で、カードの中の要素による layout-shift が 0 であることを測る。

## Risks and mitigations

- **列の幅がずれる**：12 列 + gap にして今の幅と一致させた。1280px の VRT が全ページで差分 0 になることで確かめる。
- **PJAX**：骨組みは `.main-content` の内側なので、遷移でクラスごと入れ替わる。f-12 / f-17 で確かめる。
- **sticky**：grid の子は既定で stretch なので、列は行の高さになり sticky が効く。f-08 / f-19 で確かめる。
- **hodalog への影響**：取り込み PR の CF Pages のプレビューで、ホーム・目次あり / なしの記事・タグ一覧・検索を見る。

## Validation

- 各 PR：`npm run lint`、`lint:html`、`a11y`（measure を含む）、`vrt`、`e2e`、`lighthouse`。
- measure.spec：横スクロールを 320 / 375 / 768 / 1024 / 1280 / 1440px、ホーム・目次あり / なしの記事・アーカイブ・検索・styleguide で測る。375px で `#contents` が親の幅いっぱいになること（L-10）。
- 完了の確認：`grep -rnE 'col-(sm|md)-|class="row|container-fluid' layouts assets` が 0。CSS に `order` が無い。

## Decisions

- 2026-11-14：計画をユーザーと確認した。
- 2026-11-14（5A）：`grid.css` を `layout/shell.css` に置き換えた。L-10 のテスト（375px で `#contents` が親の幅いっぱい）を先に足し、main の about で 364.7px（期待 375px）で落ちることを確かめてから直した。VRT は 1280px の全ページが差分 0。差分が出たのは、375px の全ページ（L-10 と同じ原因で、一覧のカードも中身の幅まで縮んでいた。カードもサイドバーの検索欄も全幅になった）、記事の 768px（関連記事が auto-fill で 1 列になり、題が折れなくなった）、トークン見本（`--pochi-sticky-top`）。
- 2026-11-14（5A）：Lighthouse の search の CLS が 0.131 → 0.146。P-07（結果の描画でサイドバーが下にずれる）の既知の問題で、モバイルでサイドバーが全幅になり、ずれる面積が増えた分。P7 で直す。他のページは CLS 0、全項目 100 のまま。
- 2026-11-14（5B）：いいね・シェアのレール（`#sidebar-left`）を全部の記事に出した（L-09）。目次なしの記事は `.l-shell--post-no-toc` にし、本文は今と同じ中央の 8 列（3〜10 列目）のまま、レールを 2 列目に置いた。テスト（目次なし記事の 1280px でレールのボタンが見え、本文の左にあること）を先に足し、main で落ちることを確かめた。VRT は目次なし記事の 1280px の 2 枚、outline は目次なしの記事 2 本（「いいね・シェア」の complementary が増えた）を更新した。
- 2026-11-14（5C）：`.post-row` をコンテナにし、サムネの幅をカードの幅で決める（30rem 未満で 6rem、以上で `clamp(8rem, 25%, 12rem)`。1280px で 159px で、前の 25% とほぼ同じ）。要約は `-webkit-line-clamp: 3`。カードの DOM は `.post-text` をやめて `.post-meta` と `.post-excerpt` を兄弟にした（検索のカードのテンプレートも同じ）。
- 2026-11-14（5C）：タグは先頭 3 つを `.kiji-tag.post-card-tags` で出し、`z-index: var(--pochi-z-raised)` で題のリンクの `::after` より上に置いた。チップの見た目は記事のタグと同じで、`article .kiji-tag` を `.kiji-tag` にして共用した。
- 2026-11-14（5C）：`media.css` の `padding-bottom` の比率のハックを `aspect-ratio` にした。黄金比は `1.618 / 1` だと前の 61.8% と高さが 0.03px ずれ、その下が全部サブピクセルでずれて VRT に出たので、`1000 / 618` にした。使っていない `.image-wrapper` のルールを消した。一覧のサムネの `sizes` / `widths` を表示の大きさに合わせて 192 / 384px にし、ホームの LCP が 1203 → 1078ms になった。
- 2026-11-14（5C）：example_site の p-06-pagination-5 に長い要約とタグ 4 つを足し、3 行で切ること・タグが 3 つまでなことを e2e（p-01）と VRT で確かめられるようにした。p-01 の 2 本は main で落ちることを確かめた。CLS は `tests/a11y/cls.spec.js`（ホーム・アーカイブ・タグ、375 / 1280px で、カードの中の要素による layout-shift が 0）で測る。main でも 0 なので、これは回帰の検出用。VRT はカードのあるページ（ホーム・ja のホーム・タグ・検索）を更新した。記事のページは差分 0。
- 2026-11-14（5C）：最初はカードを grid（`"thumb title" "thumb meta" "excerpt excerpt" "tags tags"`）で組んだが、和文の長い題（モバイルで 4〜5 行）だとサムネが題と日付の 2 行を縦に占め、サムネの下が大きく空いた（ユーザーの指摘。前の float では日付がサムネの下に回り込み、余白が埋まっていた）。サムネを float に戻し、題と日付が前と同じく回り込むようにした。要約は 3 行で切るために `-webkit-box`（独立したブロック）にしたので float の横には回り込めず、`clear: both` でサムネの下から全幅で始める。接頭辞なしの `line-clamp` は Chromium でもまだ効かない（`display: block` のまま切れない）ことを確かめた。題と日付がサムネより短い（題が 1 行の）カードでは、要約の上が少し空く。
- 2026-11-14（5C）：日付（`.post-info`）の `overflow: hidden` を外した。独立したブロックになって float の横に避けて置かれ、サムネより下にあるのに右に寄ることがあった（中身に float は無く、`overflow` は要らなかった）。サムネの下マージンも 0 にした（前と同じ）。マージンがあると、その分だけ日付が float の横と判定されて右に寄る。hodalog を今のテーマでビルドし、375 / 1280px のダークで確かめた。
- 2026-11-14（P5 完了）：`grid.css`・`col-*`・`order` はゼロ（stylelint でエラー）。320〜1440px で横スクロールなし（measure.spec）。カードの CLS は 0（cls.spec）。Lighthouse は search 以外が全項目 100（search の CLS 0.146 は P-07 で P7 に残す）。
