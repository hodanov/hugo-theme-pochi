# Plan: P3 WCAG 2.2 AA 準拠

デザイン磨き込みロードマップ（`2026-10-19_design-refinement-roadmap.md`）の P3。P2 で CSS の土台（トークン、`@layer`、`!important` 2 個）ができたので、監査で挙げたアクセシビリティの指摘を直す。P1 で入れた axe・html-validate・コントラストのラチェットを、P3 の終わりにほぼ空にするのが目標。

P2 と違い、見た目が変わる PR がある（3A の色・下線・操作対象の大きさ、3B の h1・404・言語切替）。意図した差分は各 PR で VRT のベースラインに載せる。

## Background

- 対象の監査 ID：A-01〜A-17、A-19〜A-23、A-25〜A-28、T-06、L-06、N-03（A-18 と A-24 は P2 で解消済み）。A-25〜A-28 は本書の調査で見つけたもので、ロードマップの A 表に追加した。
- 2026-10-20 にユーザーと決めたこと：
  - ホームの h1 は見えない h1（サイト名を `u-visually-hidden`）。セクション・タグ・カテゴリー・タグ一覧・検索・404 は見える h1。
  - 言語切替は、今の言語以外だけをリンクで出す（2 言語なら「English」か「日本語」の 1 つ）。
  - テーマ切替は、1 つのボタンで「システム → ライト → ダーク」と順に切り替える。読み上げ名は今の状態を言う。

## Current structure

棚卸し（2026-10-20、main = 2ef80f8）：

- axe（1280px だけ）の serious / critical：color-contrast（post-toc・tags・styleguide。ライトのリンク色）、link-in-text-block（styleguide）、image-alt（alt を出力しない画像、A-12）、label（styleguide のタスクリストのチェックボックス）。styleguide のダークの color-contrast 9 件は、Chroma のインラインスタイル（monokai）が中心と見ている（L-07、P7）。

## Design policy

### PR の分け方

ロードマップの 3A / 3B / 3C のうち、3B が大きい（テンプレート約 20 個と E2E 6 本）ので 2 本に分け、計 4 本にする。各 PR は単独で出荷でき、影響する E2E とベースラインは同じ PR で更新する。

1. **3A CSS**（`fix/p3a-css`）：色・下線・フォーカス・操作対象の大きさ・モーション・forced-colors。以降の PR の安全網になる計測の追加もここで入れる。
2. **3B-1 ページの骨組み**（`fix/p3b-structure`）：見出し、ランドマーク、ナビ、パンくず、ページネーション、404。
3. **3B-2 部品**（`fix/p3b-components`）：言語切替、アイコン、画像の alt、カード、いいね・シェア、検索、表、タスクリスト。
4. **3C JS**（`fix/p3c-js`）：PJAX のフォーカスと読み上げ、サイドナビの `<dialog>` 化、テーマ切替の 3 状態。

### 計測（3A で先に足す）

- `check-contrast.mjs`：ペアに `apcaMin` を持たせ、本文のペア（text-on-bg / card / surface-soft / blockquote）は Lc75 を下回ったら失敗にする。入力欄の枠のペアを card と bg の両方で持つ。下線を付けるので `link-vs-text`（G183）は外し、文章中のリンクは axe の link-in-text-block に任せる。
- a11y：`pages.js` に `viewport` を足し、375px のページ（ホーム、目次付きの記事）を加える。モバイルのアクションバーと本文中の目次を axe が見ていなかった。axe の `target-size`（24px、wcag22aa）はすでに有効なので、375px でも測れる。
- `tests/a11y/target-size.spec.js`：主要な操作対象が 375 / 1280px で 44px 以上あることを測る。
- VRT：forced-colors（Windows のハイコントラスト）の 2 枚を足す。

### リンクとフォーカス（3A）

- 記事本文（`article` の中の段落・リスト・表・引用など）のリンクに下線を付ける。目次・タグ・脚注など部品のリンクは部品側で消す。
- `:focus-visible` のリングを `base.css` で 1 か所に定義し、部品は「内側に描く」などの差分だけを持つ。`:focus { outline: none }` は消す。
- `html` に `scroll-padding-top`（固定ナビ）と、モバイルでは `scroll-padding-bottom`（アクションバー）を指定する（2.4.11 Focus Not Obscured）。
- `smoothScroll()` は `scrollIntoView()` に任せて scroll-padding を効かせ、移動先にフォーカスを移す。URL の hash は今どおり書き換えない（hash を変えると popstate で PJAX が同じページを読み直す）。

### 操作対象・モーション・forced-colors（3A）

- `--pochi-target-min: 44px` を足し、主要な操作対象（メニュー、テーマ切替、ドロワーを閉じる、コードのコピー、トップへ戻る、いいね・シェア・はてな、検索ボタン）に当てる。タグ・ページ番号・サイドバーのリンクは 24px 以上（2.5.8）。
- reduced-motion のときは `--pochi-duration-*` を 0s にする（tokens.css で一括）。見た目だけのホバー効果は `@media (hover: hover)` に入れる。ドロップダウンを開く `:hover` は機能なので残す（タッチでは 3B-1 の開閉ボタンで操作する）。
- 引用の斜体をやめる（T-06。和文が擬似斜体になる。左の線と背景で引用と分かる）。
- forced-colors のときに、背景や影だけで表していたもの（ドロワーの「×」、押したいいね、現在のページ番号、チップ、カードの境界）に `CanvasText` や透明な枠を足して見えるようにする。

### 構造（3B-1）

- h1：ホームは見えない h1 にサイト名。セクション・タグ・カテゴリー・タグ一覧・検索は見える h1 にページ名。コメントと関連記事の見出しは h3 → h2。
- 目次：本文中とサイドバーの `<nav id="TableOfContents">` のうち本文中の方の id を変え、どちらも見出しを `aria-labelledby` で指す。1 つにまとめるのは P5 のグリッド化で。
- ナビ：`role="menu"` をやめ、APG の Disclosure Navigation（親のリンクの隣に `aria-expanded` の開閉ボタン）にする。example_site のメニューに子を足す。
- パンくず：区切りを `aria-hidden` の `<span>` にし、最後の項目に `aria-current="page"`。「Home」を i18n に。
- ランドマーク：`role="main"` を消す。`<aside>` は中の h2 を `aria-labelledby` で指す（見出しが無いものは `aria-label`）。トップへ戻るボタンは `<footer>` の中へ。固定ページのヒーローは `<main>` の中に入れ、`navigation.js` のヒーローの差し替えを消す。
- ページネーション：自前の partial にし、`<nav aria-label>` と `aria-current="page"` を付け、role を付けない（A-25）。
- 404：h1、説明、検索フォーム、ホームへのリンク、最新 5 件（N-03）。

### 部品（3B-2）

- 言語切替：`<select>` をやめ、今の言語以外へのリンク（`hreflang` と `lang` 付き）にする。`lang-switcher.js` は消す。
- アイコン：`aria-hidden="true"`、`focusable="false"`、`href`。日付には見えない「公開日」「更新日」を添える。
- 画像：alt が空でも `alt=""` を出す。カードのサムネイルは `alt=""`（見出しが名前になる）。
- カード：`<h2><a>` ＋ `::after` でカード全体をクリック範囲にする（Inclusive Components の Cards）。見た目は変えない。
- いいね：名前を「いいね」に固定し、件数は `aria-describedby` で添える。シェア：1 回きりの操作なので `aria-pressed` をやめ、通知の live region をボタンの外に出す。
- 検索：`type="search"`、件数を読み上げる `role="status"`。
- 表：render hook で `role="region"`・`tabindex="0"`・ラベル付きのスクロール領域に包む（L-06）。
- タスクリスト：`.Content` を出す箇所を 1 つの partial にまとめ、チェックボックスに「完了」「未完了」の名前を付ける（A-28）。

### JS（3C）

- PJAX：差し替えが終わったら新しいページの h1（無ければ main）にフォーカスを移し、`.main-content` の外の live region でタイトルを読み上げる。戻る / 進むではフォーカスを動かさない。
- サイドナビ：`<dialog>` と `showModal()`。フォーカスの閉じ込め・背景の不活性化・Esc・閉じた後の戻り先はブラウザに任せ、tabindex の付け替えと overlay の div を消す。開閉のアニメーションは `@starting-style` と `transition-behavior: allow-discrete`（非対応のブラウザでは即時に開閉する）。
- テーマ切替：`pref-theme` が無ければシステムに従う（head のスクリプトは今のまま）。OS の設定の変化はシステムのときだけ反映し、`localStorage` に書かない。`theme-color` を選んだテーマに合わせ、`syncHead()` は `theme-color` を同期しない（P2 の Open question）。

## Risks and mitigations

- **カードの `::after`**：カードの文字が選択しにくくなる。中に別のリンクを置くと押せなくなるので、カードの中のリンクは見出しの 1 つに保つ。
- **ヒーローを main に入れる**：固定のヒーローと main の重なり順が変わる。VRT の about（5 枚）で検出する。崩れが大きければ `<section aria-labelledby>` で包むだけにして P5 に送る。
- **`<dialog>` と PJAX**：サイドナビは `.main-content` の外なので差し替わらない。開いたまま遷移したら閉じる。
- **PJAX のフォーカス**：View Transitions の更新が終わってから移す。`preventScroll` でスクロール位置を動かさない。
- **コピーボタンを 44px にするとコードの 1 行目に重なる**：VRT の sg-code で確かめ、必要なら `pre` の上の余白で逃がす。
- **サイトへの影響**：hodalog はテーマを上書きしていないので、そのまま反映される。新しい i18n のキーは en / ja の両方に足す。取り込み PR の CF Pages プレビューで、問い合わせページ・ドロップダウン・言語リンクを見る。

## Decisions

- 2026-10-20：3B を 2 本に分け、PR を 4 本にした。
- 2026-10-20：ホームの h1 は見えない h1、言語切替は今の言語以外へのリンク、テーマ切替は 1 つのボタンで 3 状態を順に回す（ユーザーと決定）。
- 2026-10-20：文章中のリンクは下線で区別する（G183 の 3:1 には頼らない）。リンク色を暗くすると本文色との差がさらに縮むため。

- 2026-10-20（3A）：新しい色は、リンク `#1f7a6d`（`--pochi-teal-52`）、必須マーク `#b44159`（`--pochi-pink-54`、白で 5.47）、入力欄の枠 `#858585`（`--pochi-gray-62`）、ダークの本文 `#d0d7de`（`--pochi-slate-88`）。どれも OKLCH で書き、8bit に丸めて元の hex に戻ることを確かめた。コントラストの `known` は 0 になった。ダークの本文色を元に戻すと、APCA の下限で check-contrast が落ちる。
- 2026-10-20（3A）：サイドバーの検索欄は、入力欄にもボタンにも枠が無く（`border: none`）、背景との差 1.09:1 でしか範囲が分からなかった。入力欄とボタンを囲む `.input-group` に `--pochi-border-control` の枠を付けた。
- 2026-10-20（3A）：コピーボタンを 44px にすると、モバイルではコードの 1〜2 行目に重なり、1 行だけのコードではブロックの下にはみ出した。ボタンが付いた `pre` は上の余白を `max(カードの余白, 44px + 1rem)` にして、コードがボタンの下から始まるようにした（デスクトップは 10px、モバイルは 44px 増える）。
- 2026-10-20（3A）：`[tabindex="-1"]:focus-visible` のリングを消すルールは、ページ内リンクで移った見出しや main のためのもの。閉じたドロワーの中のボタンにも JS が `tabindex="-1"` を付けるので、`a, button, input, select, textarea` は対象から外した（3C で `<dialog>` にすれば付け替え自体が無くなる）。
- 2026-10-20（3A）：脚注だけに付けていた `scroll-margin-top` は、html の `scroll-padding-top` と足し算になるので消した。E2E の f-16 は「scroll-margin があること」から「移動先がナビの下に出ること」を確かめる形に変えた。f-16 と新しい f-19 は、scroll-padding を 0 にすると落ちることを確かめた（短い記事だと見出しが上端まで届かず、余白が無くても通ってしまったので、長いページで測る）。
